# 연구실 전력 배치도 (열람용)

연구실 콘센트·멀티탭·장비의 연결 상태와 전력 부하를 보는 페이지입니다. 편집은 할 수 없습니다.

**바로 보기:** https://tansan7271.github.io/lab-power-map/

## 보는 법
- 멀티탭이나 벽 콘센트를 누르면 연결된 것들만 떠올라 계층별로 정렬됩니다 (위: 벽 콘센트 → 멀티탭 → 아래: 기기). "지도에서 보기"를 누르면 지도 위 강조로 돌아갑니다.
- 기기를 누르면 벽 콘센트까지 이어지는 전원 경로가, 책상을 누르면 그 자리의 장비가 보입니다.
- 전선의 ● 쪽이 전원(콘센트·멀티탭), ❯ 쪽이 꽂힌 기기입니다. 주황 점선은 멀티탭에 멀티탭을 꽂은 연결입니다.
- 휴대폰에서는 아래 탭으로 지도 / 목록 / 요약을 오갑니다. 두 손가락으로 확대할 수 있습니다.

기기 W는 정격(최대) 기준이라 실제 사용량보다 크게 잡혀 있습니다.

## 데이터 갱신
편집기에서 **내보내기**한 JSON을 `data.json`으로 바꿔 넣고 push하면 됩니다.

```sh
./update.sh                 # ~/Downloads 의 가장 최근 전력배치_*.json 으로 갱신
./update.sh path/to/file.json
```
